Hyper-Accelerated HTTP/S & Stream Engine (velo-http)Dynamic Range Splitting & Work Stealing: Splits large files into up to 64 concurrent byte-range connections. When a fast worker finishes its chunk early, it automatically steals the remaining half of the slowest worker's byte range so tail latency never bottlenecks completion.HTTP/2 & HTTP/3 (QUIC) Multiplexing: Negotiates HTTP/3 over UDP where supported to eliminate TCP head-of-line blocking on high-latency or lossy VPN/proxy links.Native HLS (.m3u8) & DASH (.mpd) Assembly: Parses master playlists, decrypts AES-128 / SAMPLE-AES media segments in memory, downloads video and audio segments concurrently, and muxes them into .mp4 or .mkv containers.Crash-Proof Atomic Resume (.velo.part + .velo.json): Persists per-chunk byte offsets and rolling BLAKE3/SHA-256 block hashes to disk every 500ms. Power loss, VPN reconnects, or expired signed CDN links can be resumed without re-downloading completed bytes.2. Universal Website Extractor Engine (velo-extractor)Two-Tier Extraction Pipeline:Tier 1 — Native Rust Extractors: Zero-overhead compiled Rust parsers for direct file hosts, raw manifests (.m3u8, .mpd), GitHub releases, S3/R2 buckets, and open directories.Tier 2 — Managed yt-dlp Extractor Bridge: Automatically queries an embedded or system yt-dlp --dump-single-json subprocess to resolve video, audio, playlist, and subtitle streams from 1,000+ websites, then hands the resolved stream URLs directly to Velo's multi-connection Rust engine and privacy layer.Interactive Stream & Quality Selector: Pick exact video resolutions (4K, 1440p, 1080p60), codecs (AV1, HEVC, VP9, Opus, FLAC), subtitle languages, and chapter splits directly inside the terminal UI before downloading.3. Safe, Masked BitTorrent Engine (velo-torrent)Forced Message Stream Encryption (MSE / PE): Rejects plaintext BitTorrent handshakes when stealth mode is active, forcing RC4/MSE stream obfuscation so deep-packet inspection (DPI) boxes cannot throttle or flag P2P packets.Tracker & Peer Sanitization: Blocks unencrypted http:// and plaintext udp:// trackers when strict privacy mode is enabled, routing tracker announces exclusively through HTTPS or SOCKS5/Tor proxies.Anonymous Swarm Profile: Randomizes peer ID prefixes and ephemeral listening ports on every session, disables Local Peer Discovery (LPD) on untrusted LANs, and strips client version strings and local IPv4/IPv6 headers from extended BEP-10 handshakes.Selective File & Sequential Piece Prioritization: Preview the file tree inside .torrent archives or magnet metadata before allocating disk space, select individual files, or enable sequential piece order for live media previewing.4. Zero-Leak Privacy & Masking Shield (velo-privacy)Socket-Level VPN Interface Binding (Hard Kill Switch): Binds every TCP and UDP socket directly to your designated VPN or WireGuard interface (wg0, tun0, utun4, proton0) via OS socket options (SO_BINDTODEVICE on Linux, IP_BOUND_IF on macOS, interface index binding on Windows). If the VPN tunnel drops for even 1 millisecond, Velo halts all packets at the kernel boundary—never falling back to your home or Wi-Fi IP.Encrypted DNS Resolution (DoH & DoT): Bypasses your system's /etc/resolv.conf and ISP DNS servers completely. All domain lookups run through hickory-resolver over encrypted DNS-over-HTTPS (Cloudflare, Quad9, Mullvad, or custom endpoints) so your ISP cannot see which websites or tracker domains you query.Multi-Hop SOCKS5 & Tor Routing: Supports per-task or global socks5:// and socks5h:// (remote DNS resolution) proxies, including automatic Tor control-port (NEWNYM) circuit rotation between downloads.Anti-Fingerprinting Browser Emulation: Rotates realistic browser User-Agent strings, Sec-Fetch-* headers, Accept-Language locales, and request jitter timing so CDNs see standard desktop browser traffic rather than automated downloader signatures.Cargo Workspace ArchitectureCrate PathCrate TypeResponsibilitycrates/velo-cliBinary (velo)clap CLI subcommands, ratatui + crossterm full-screen OpenCode-style TUI, slash-command parser, and theme engine.crates/velo-coreLibraryCentral async task scheduler, unified state machine, bandwidth token bucket, disk ring buffer, and event bus.crates/velo-privacyLibraryVeloNetContext builder, DoH/DoT DNS resolver, SOCKS5/Tor dialer, OS socket interface binder, and TLS/header rotator.crates/velo-httpLibraryMulti-connection Range work-stealing downloader, HLS/DASH decryptor & segment combiner, and checksum verifier.crates/velo-extractorLibraryURL router, native Rust site extractors, and managed yt-dlp JSON bridge with stream format selector.crates/velo-torrentLibraryAsync BitTorrent/magnet engine with MSE/PE encryption enforcement, selective file trees, and tracker sanitizer.assets/velo-logo.svgVector AssetOfficial Velo vector emblem and wordmark.Installation & Building from SourcePrerequisitesRust Toolchain: 1.85+ (curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh)Optional Helpers: yt-dlp (for 1,000+ site fallback extraction) and ffmpeg (for multi-track video/audio stream merging).Clone & Build# Clone the Velo repository

CLI Usage Reference# Launch the full-screen OpenCode-style Terminal UI workspace
velo

# Download any direct file with 16 parallel connections and automatic resume
velo get https://releases.ubuntu.com/24.04/ubuntu-24.04-desktop-amd64.iso -x 16

# Download a video from any website in 4K MP4 with embedded English subtitles
velo get "https://example.com/watch?v=id" --quality 2160p --container mp4 --subs en

# Extract audio only as lossless FLAC
velo get "https://example.com/watch?v=id" --audio-only --audio-format flac

# Download with Ghost Privacy Profile (DoH + SOCKS5/Tor + randomized headers)
velo get https://example.com/dataset.tar.zst --stealth ghost --proxy socks5h://127.0.0.1:9050

# Download a magnet link locked strictly to WireGuard interface wg0 with forced MSE encryption
velo torrent "magnet:?xt=urn:btih:..." --bind-interface wg0 --encryption forced --no-http-trackers

# Run a full privacy, DNS leak, VPN interface, and IP masking audit
velo doctor --leak-test
